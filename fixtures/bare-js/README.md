# fixture: bare-js

A plain **JavaScript** Next.js app (App Router) — no TypeScript: `.jsx` components, a CommonJS
`next.config.js`, and a `jsconfig.json`.

**Exercises:** the JS code path. Real Next.js apps come in both JS and TS, so the plugin must handle a
JS project — reading a CommonJS `next.config.js` and (later) scanning `.js`/`.jsx` files — not just
TypeScript. The `bare` fixture is the TypeScript counterpart.
